# 📓 FTW Data Engineering Learning Journal

Welcome to my Data Engineering learning journal.

This repository documents my journey through the **FTW Foundation Data Engineering Fellowship**, including class reflections, key concepts learned, questions I still have, and my progress in Git, GitHub, SQL, Databricks, data modeling, and data engineering best practices.

The goal of this repository is not to create perfect notes, but to build a consistent learning habit while practicing version control and technical documentation.

---

## 🎯 Learning Goals

- Understand data engineering fundamentals
- Learn SQL and Databricks
- Build data pipelines using Medallion Architecture
- Practice dimensional modeling and star schemas
- Improve Git and GitHub workflows
- Develop documentation habits used by professional data teams
- Document my growth from Data Analyst to Aspiring Data Engineer
